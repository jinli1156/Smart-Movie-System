# AI 观影纪念票

用户在完成支付后，可从“我的订单”“订单详情”或个人中心的观影记录中，生成并收藏一张专属纪念卡。主题固定为**星空科幻**：深蓝、紫蓝星云、宇宙光轨、未来感粒子与全息发光边框。纪念票不具备入场效力。

## 生成与保存

- AI 只创作不含文字的背景及纪念短句。程序将电影名、影院名、场次时间、影厅、座位和真实订单尾号绘制到票面上，输出 **1080 × 1560 PNG**；“AI 创作 · 仅作观影纪念 · 非入场凭证”由程序固定绘制。
- 文案请求只发送影片名、类型、简介和用户选填的心情，不发送订单号、座位和取票凭证。生成的图片不包含取票码、二维码或完整订单号。
- 复用现有 `MarketingTextClient` 和 `MarketingImageClient`，使用已有的文案与生图配置，**不使用 ComfyUI**。画面提示词始终附加固定蓝紫星空主题和禁止文字要求。
- 任务异步执行，关闭窗口不会取消任务；再次进入订单会恢复进度。每笔订单只保留一张，相同订单的并发提交返回同一个任务。
- 下载图片后可自行分享。支持文件分享的浏览器使用系统分享面板；其他浏览器下载 PNG 后提示用户分享图片。

## 订单与任务规则

服务端只允许订单本人生成和读取纪念票，管理员也不能代其他用户生成。创建与开始执行时均核验订单仍为已支付状态；待支付、取消、退款订单禁止生成。任务创建时保存订单和影片快照，后续修改影片资料不会影响已保存的纪念卡。

每日每用户最多创建 6 张（北京时间，按新建任务计数）；单任务最多提交 3 次。订单行锁、用户行锁和数据库唯一键共同保护额度与幂等。没有自动重试模型调用；只有明确失败的任务允许手动重试，结果未知的生图请求不再提交。已获得图片结果但转存失败时，重试只继续下载和排版，复用已持久化的图片结果。

任务状态为 `QUEUED → RUNNING → SUCCEEDED / FAILED`。后台最多同时执行两个任务；超过 20 分钟未更新的执行任务标记为中断，有已保存的图片结果才允许手动继续。没有配置完整的 AI 服务时，界面显示服务尚未开放，并禁用生成；已经保存的纪念票仍可下载。

## 配置与部署

启动 Spring Boot 会通过 **Flyway V27** 新增 `souvenir_ticket` 表。默认图片文件位于后端工作目录相对路径 `../.local/souvenir-assets`，由校验用户身份的接口提供，不放入公共上传目录。生产环境应将该目录映射到持久化存储，并安装可用的中文字体（当前排版使用 Microsoft YaHei）。

可使用 Spring 环境变量覆盖：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `SOUVENIR_WORKER_ENABLED` | `true` | 开启后台生成 |
| `SOUVENIR_STORAGE_PATH` | `../.local/souvenir-assets` | 私有图片目录 |
| `SOUVENIR_DAILY_LIMIT` | `6` | 每用户每天新建任务上限 |
| `SOUVENIR_POLL_INTERVAL_MS` | `2000` | 服务端任务扫描间隔 |

复用 `marketing.*` 生图参数及文本服务设置，密钥继续放在被 Git 忽略的 `.local/marketing.properties`、`.local/assistant.properties` 或环境变量中。远程生图请求沿用本机 HTTP 代理 `http://127.0.0.1:7890`，本机地址直连。

## 接口与验证

所有接口位于 `/api/souvenirs`，要求登录：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/capabilities` | 主题、配置状态与额度 |
| GET | `/orders/{orderNo}` | 订单本人的生成记录 |
| POST | `/orders/{orderNo}` | 创建或手动重试，参数 `{ "note": "选填心情", "retry": false }` |
| GET | `/{id}/file` | 读取本人 PNG 图片，禁止缓存 |

验证命令：后端 `mvnw.cmd -Dtest=SouvenirServiceTest,MarketingImageClientTest test`；用户端 `npm run build` 与 `npx playwright test e2e/souvenir.spec.ts`。覆盖真实 Spring 事务中的并发提交、模型传参、图片排版、读取权限、订单状态、额度、失败恢复和浏览器下载。浏览器及服务测试中的模型传输使用替身，不代替真实模型联调。

本功能接入 Spring Boot 与 Vue 用户端；独立 uniCloud 迁移副本尚未同步。
