## 本次修复

生产构建检查发现，页面 CSS 中的 Google Fonts `@import` 请求失败会使 Vite 的异步 CSS 预加载失败，导致海报、订单等页面无法渲染。已将用户端各页面的外部字体引用集中到 HTML 独立 `link` 中；管理端移除重复的 CSS 字体引用并保留 HTML 字体配置。字体不可访问时，页面仍可正常加载并使用字体回退。

管理端生产检查还发现 `vendor-element-date` 与 `vendor-element-plus` 相互依赖，浏览器出现 `Cannot access ... before initialization`，页面无法显示。已将日期控件及 dayjs 合并到同一个 Element Plus 资源包，消除这组循环依赖。
