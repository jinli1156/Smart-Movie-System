## API接口清单

### 订单管理
- POST /api/order - 创建订单
- GET /api/order/my - 我的订单列表
- GET /api/order/page - 管理端订单列表
- GET /api/order/{orderNo} - 订单详情
- POST /api/order/{orderNo}/pay - 支付订单
- POST /api/order/{orderNo}/cancel - 取消订单

### 场次管理（新增）
- GET /api/showtime/{id}/seats - 获取座位状态

## 完整购票流程

### 用户操作流程
1. 访问首页，浏览电影
2. 点击电影卡片，进入详情页
3. 选择影院和日期
4. 选择场次
5. 登录（如未登录）
6. 进入座位选择页
7. 点击Canvas选择座位
8. 确认选座
9. 填写备注（可选）
10. 提交订单
11. 支付订单
12. 查看订单详情

### 系统处理流程
1. 验证用户登录状态
2. 验证场次有效性
3. 锁定选中的座位（Redis）
4. 创建订单记录
5. 更新可用座位数
6. 返回订单号
7. 用户支付
8. 更新订单状态
9. 记录支付时间

### 取消订单流程
1. 验证订单状态（只能取消待支付）
2. 更新订单状态为已取消
3. 恢复可用座位数
4. 释放Redis座位锁

## 数据流转

```
用户 → 电影列表 → 电影详情 → 场次列表 → 座位图 → 订单确认 → 支付 → 订单详情
                                    ↓
                            Redis座位锁
                                    ↓
                            MySQL订单表
```
