## 技术亮点

### 推荐算法

#### 1. 热门推荐算法
```
热度分数 = 评分分数 + 订单分数 + 时间分数

评分分数 = 电影评分 × 10
订单分数 = 近7天订单数 × 2
时间分数 = max(0, 100 - 上映天数)
```

**特点：**
- 综合多维度数据
- 时间衰减机制
- Redis缓存优化

#### 2. 个性化推荐
- 基于用户观影历史
- 过滤已观看电影
- 按评分排序
- 未登录用户显示热门推荐

#### 3. 相似电影推荐
- 基于电影类型匹配
- 计算类型重叠度
- 按相似度排序
- 最多返回6部
