# 毕业设计创新点与实验复现

本文记录两项核心创新的实现边界、实验方法和答辩时可复现步骤。所有预测值属于决策模拟，不代表真实经营承诺。

## 一、严格时间切分的可解释混合推荐

### 实现

- 线上模型融合时间衰减、影片内容、显式偏好、行为相似、场景、七日趋势和多样性重排。
- 每部推荐影片返回总匹配分、五项分量和自然语言推荐理由。
- 用户端展示五维偏好雷达图：内容契合、显式偏好、行为相似、场景适配、近期趋势。
- 离线实验严格以用户最后一次想看时间为分界，只读取该时刻之前的行为、订单、评价与趋势。
- 管理端同时展示完整模型、热门/纯内容基线，以及去时间衰减/场景/多样性的消融实验。

### 指标

报告 `Precision@K`、`Recall@K`、`NDCG@K`、目录覆盖率和列表多样性。实验接口为：

```http
GET /api/recommend/evaluation?k=6
```

更完整的切分和指标定义见 [RECOMMENDATION_EVALUATION.md](RECOMMENDATION_EVALUATION.md)。

## 二、约束条件下的多目标智能排片

### 决策模型

求解器使用 Google OR-Tools CP-SAT。对每个“影片 × 影厅 × 半小时时刻”建立 0/1 决策变量，并使用可选区间变量表达影片时长和清场占用。

硬约束包括：

1. 同一影厅的场次区间不能重叠；
2. 每场结束后预留可配置的 10–60 分钟清场时间；
3. 每厅达到目标场次数，已经售票或已经开始的场次强制锁定；
4. 单部影片不超过给定场次上限，历史锁定场次超过上限时不删除真实场次；
5. 方案达到最低影片数；
6. 每个影厅在 18:00–22:00 达到最低黄金时段场次数；
7. 预计观众数按影厅座位容量封顶，影片时长决定结束时间，最晚在次日 02:00 前完成清场。

目标函数为三个归一化目标的加权和：

```text
maximize 收入权重 × 预计收入
       + 上座率权重 × 预计上座率
       + 多样性权重 × 被采用的不同影片数
```

三个权重必须合计 100。管理员可配置目标日期、影片范围、每厅场次、单片上限、最低影片数、清场时间、黄金时段最低场次和求解时限。

### 对照实验

一次求解在同一候选集上输出三种方案：

| 方案 | 定义 |
|---|---|
| 人工现状 | 目标日期数据库中已有排片 |
| 加权启发式 | 按局部效用依次选择不冲突场次 |
| CP-SAT 多目标优化 | 在全部硬约束下联合求解全局目标 |

报告预计收入、预计观众、预计上座率、影片数、计算耗时、约束满足率，以及 CP-SAT 相对人工/启发式的收入和上座率变化。接口为：

```http
POST /api/statistics/scheduling/optimize
```

管理端“智能排片建议”页可直接运行。求解结果不会写回 `showtime` 表，防止实验操作覆盖真实排片。

### 排片预测评估

原有“同批数据拟合并预测自身、用 100-MAE 表示准确率”的做法已移除。现在将历史场次按开场时间升序切分：前 80% 构建统计模型，后 20% 仅测试；报告 MAE、RMSE、MAPE、全局均值基线 MAE及相对提升。MAE 是误差而不是准确率，数值越低越好。

## 三、论文实验建议

1. 导出并冻结同一份数据库快照，记录有效用户数、历史场次数和实验日期。
2. 推荐实验至少报告多个 K 值，并给出完整模型相对两种基线和三种消融的表格。
3. 排片实验选择工作日、周末各若干天，保持影片集合和约束一致，重复记录三种方案。
4. 将离线预测和模拟结果表述为“预计提升”，不要写成已发生的真实营收提升。
5. 若要做显著性检验，可按用户保存推荐指标、按日期保存排片指标，再进行配对 bootstrap 或 Wilcoxon 检验。
