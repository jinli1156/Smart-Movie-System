# 混合推荐实验说明

## 行为权重

| 行为 | 基础权重 |
|---|---:|
| 浏览 | 1（单片最多累计 3 分） |
| 想看 | 3 |
| 已支付购票 | 5 |
| 五星评价 | 6 |

所有行为应用时间衰减 `max(0.35, 0.97^距今天数)`，避免很久以前的兴趣长期主导推荐。

## 混合得分

候选影片总分由内容相似度 30%、用户显式偏好 15%、行为相似度 20%、场景因素 20%、热门趋势 15% 构成。

- 内容相似度：类型 35%、导演 20%、演员 20%、语言 15%、片长 10%。
- 场景因素：未来七天是否有可售场次、48 小时内场次、最低票价、用户与影院距离。
- 热门趋势：影片评分 70%、最近七天已支付订单销量 30%。
- 多样性：重排时同一主类型最多占推荐列表的 50%（至少允许 2 部），并对与已选影片过于相似的候选项施加 MMR 风格惩罚。

## 离线评估

管理员调用：

```http
GET /api/recommend/evaluation?k=6
```

评估采用按用户时间顺序的 leave-one-out：留出最近一次“想看”作为测试正样本，只用此前行为重建画像。

- `Precision@K = 命中的测试正样本数 / (用户数 × K)`
- `Recall@K = 命中的测试正样本数 / 测试正样本总数`
- `Coverage = 所有推荐结果涉及的不同影片数 / 可推荐影片总数`
- `Diversity`：列表内所有影片对的平均 `1 - 类型 Jaccard 相似度`

论文实验应固定数据快照、K 值和时间窗口，并同时报告被评估用户数；用户数过少时指标不具有统计意义。
