## 云端适配

- 新建 5 个禁止客户端直接读写的集合：`mts_ai_job`、`mts_ai_quota`、`mts_ai_lock`、`mts_listing_draft`、`mts_marketing`，并上传索引。现有业务数据未重导或重置。
- `movie-ai-worker` 仅由 API 的内部调用按需处理，最长 120 秒、每次最多 2 个任务。遗留年度占位触发调用直接返回，不读数据库或执行模型；完整删除仍待控制台。可能已提交的生图请求不自动重放。
- 参考照片与私有成品使用 AES-256-GCM 加密。阿里云文件通过临时存储 URL 下载并在服务端解密，不调用该云不支持的服务端 `downloadFile`。
- URL 化网关对 multipart 上传存在解析差异，新页面显式使用 JSON/base64 传输；上架文件合计限 1.3MB，人物照片限 1.4MB。
- 网关限制大响应，私有原图通过每段 512KB、逐段鉴权下载，在浏览器还原原始 PNG；公开营销展示使用体积受控的预览图。
- 文字沿用 DeepSeek；生图按已有配置使用 `qwen-image-3.0`；图文识别沿用 GLM 配置，限流时使用已配置的 Qwen 原生图文接口。
- Noto 字体保留许可证并转换为 TrueType，避免纯 JavaScript 排版器对 CID/CFF 字体的兼容问题。
